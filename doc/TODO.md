# Riddle Android 后续开发清单

## Phase 2：工具型 Agent

状态：暂不纳入 Android 首个可用版本。

首个版本只实现：

- 全屏魔法纸张手写；
- 停笔自动提交；
- 用户墨迹淡出；
- 模型回复逐笔写回；
- 支持不同手机和平板尺寸；
- OpenAI/ChatGPT-compatible、DeepSeek-compatible 等多模型配置；
- 视觉模型直接读取页面图片；
- 非视觉模型通过本地手写识别获得文字；
- 本地对话记忆和历史页面重现。

后续 Phase 2 再实现工具型 Agent，候选能力包括：

- 读取用户授权的文件或文档；
- 创建提醒和日历事件；
- 打开应用或系统页面；
- 调用经过白名单注册的 Android 能力；
- 工具调用参数校验和结果裁剪；
- 只读、可逆写入、外部副作用和禁止操作分级；
- 外部副作用执行前的逐次用户确认；
- Prompt Injection 隔离；
- 工具调用次数、运行时间和输出大小限制；
- 工具执行审计、隐私脱敏和失败恢复；
- 工具调用及审批状态在进程重建后的恢复。

实现 Phase 2 前必须单独创建并审批 SDD 规格，不得直接把工具执行逻辑加入聊天 UI 或模型 Provider。
